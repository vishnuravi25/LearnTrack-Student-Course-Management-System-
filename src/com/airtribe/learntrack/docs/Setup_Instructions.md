# Setup Instructions

## JDK Version Used
- JDK Version: Java 26
- Installed from: Oracle / OpenJDK

## Steps to Install & Configure Java

1. Download the JDK from the official website (Oracle or OpenJDK).
2. Install the JDK by following the setup instructions.
3. Set environment variables:
    - Set JAVA_HOME to the JDK installation path
    - Add the bin folder inside JDK to the system PATH

4. Verify installation by running:
      - Java - Version
